# 可视化

可视化使用 Plotly，各模块的职责如下：

- `campus_diagram.py`：根据本地图面布局绘制场地、建筑、道路示意和地点名称。
- `user_markings.py`：根据用户标注近似绘制道路、禁行线、天桥及校门线索。
- `campus_navigation.py`：在示意图上叠加可通行网格、A* 扩展节点、分层路径和起终点。
- `apk_places.py`、`osm_reference.py`：读取本地参考资料并作坐标或边界辅助分析，不负责生成已核实道路。

图面坐标不是经纬度，绘制的线条和地点不自动证明真实通行；数据来源与限制见 `note/校园地图资料.md` 和 `note/校园地图与道路采集.md`。
