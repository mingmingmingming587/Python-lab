# 地图显示

当前运行代码为 `pdf_map.py`：以行列显示 180×90 分类网格、可选 PDF 图面、A* 扩展与路径格，以及手动建筑标记。底图与网格使用同一裁切区域，坐标从 0 开始。

黄为建筑，绿为道路，红为边界，浅灰为未标注；蓝为路径，橙为搜索扩展。建筑标记可以在不可通行的建筑格内，标记本身不充当导航入口。旧图与 APK/OSM 的显示脚手架已移除，历史实现保留在 experiment 分支。

呈现优化后，默认不叠加 PDF，也不绘制细网格缝隙；保持原分类数据，以柔和色块显示。所有地点使用同一圆点，类型放到悬停文本；选中地点单独高亮名称。扩展节点由 show_visited 控制，默认隐藏。focus 根据当前路线或所选地点计算显示范围，不修改数据，也不参与 A*。各页面在地图顶部提供“图层与视图”。
