# 地图数据库

`pdf_map.py` 从新 PDF 提取 180×90 分类，并只将道路格转为可通行。`campus_project.py` 的 `CampusMapService` 接收初始地图状态与数据库路径，使用 SQLite 保存地图版本和查询快照。

数据库文件为 `data/campuspath-integrated.db`，保存在本机。五张业务表由 `campus_project.py` 初始化：

| 表 | 保存内容 |
| --- | --- |
| `maps` | 地图名称、大小、来源、指纹、标记版本和修订号 |
| `map_cells` | 每个格子的行列与分类，使用 `(map_id, row, col)` 作为主键 |
| `places` | 所属地图、地点名称、类型、标记位置和状态说明 |
| `place_entrances` | 所属地点、入口名称、行列和启用状态 |
| `campus_route_history` | 所属地图、查询时间、起终点、路径、扩展节点和查询快照 |

地图加载时依据分类生成二维通行网格。保存修改时先校验地图修订号，再在事务中写入相关表。地点和入口使用外键关联，入口是否可用还要看当前格子是否可通行。

首次打开旧版单层数据库时，会在同一个事务中创建五张表、复制当前地图和历史记录，再移除旧表。迁移保留地图修订号、地点备注、入口状态及查询快照。旧版三维快照读取时会转换为二维。迁移失败时 SQLite 回滚整个事务。
