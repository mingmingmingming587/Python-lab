# 地图数据库

`pdf_map.py` 加载 180×90 初始分类和 PDF 底图，只将道路格转为可通行。`campus_project.py` 的 `CampusMapService` 接收初始地图状态与数据库路径，使用 SQLite 保存地图修订和查询快照。

数据库文件为 `data/campuspath-integrated.db`，保存在本机。固定使用一张地图，五张业务表由 `campus_project.py` 初始化。

| 表 | 保存内容 |
| --- | --- |
| `maps` | 固定 ID、名称、大小、修订号和网格来源指纹 |
| `map_cells` | 每个格子的行列与分类，使用 `(row, col)` 作为主键 |
| `places` | 地点 ID、唯一名称、类型、标记位置和状态说明 |
| `place_entrances` | `place_id` 同时为主键和外键，保存入口名称、行列、启用状态及来源 |
| `campus_route_history` | 查询 ID、时间、起终点、结果、路径、扩展顺序和查询快照 |

地图加载时依据分类生成二维通行网格。保存修改时在同一个事务中替换地图数据并递增修订号。修订号用于显示版本和刷新导航结果。地点和入口使用外键关联，入口是否可用还要看当前格子是否可通行。

入口来源 `source` 为 `manual`（手工录入）或 `map_inferred`（图面推定，待核实）。初始地点和入口在建库或手动恢复初始地图时加载。地图来源说明和固定版本从项目资料获取，导出 JSON 继续携带它们。

当前数据库结构版本为 4。旧多入口优先保留已启用且当前道路可通行的入口。历史步数和扩展节点数由读取层根据路径和扩展顺序计算。回退旧版本时可配套使用本机数据库备份，本次精简前的备份文件名为 `data/campuspath-integrated.before-single-map-*.db`。

首次打开旧版单层数据库或此前的五表数据库时，程序在同一事务中复制当前地图和查询历史。地点备注、入口状态和历史快照都会保留。旧版三维快照读取时会转换为二维。迁移失败时 SQLite 回滚整个事务。
