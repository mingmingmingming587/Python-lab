# 校园地图与数据接口

校园地图固定使用一张 180 行 × 90 列的二维网格，地点、入口和路径坐标统一为 `(row, col)`，行列从 0 开始。

## 底图与网格

`reference/campus-map-basemap.pdf` 是用户提供的单页底图，保留建筑轮廓和文字。程序渲染并裁切 PDF 的 `(95.811462, 43.870117, 500.440125, 858.226929)` 区域，与网格对齐。

初始分类保存在 `reference/initial-grid.json`。分类提取自 `reference/campus-map-integrated.pdf` 第 2 页，逐格对照第 3 页的道路。三页 PDF 用于核对数据来源，程序直接加载 JSON 网格。底图指纹和网格来源指纹 `source_hash` 分别校验，更换底图时需要核对裁切与网格边界。

| 分类值 | 含义 | 初始格数 |
| --- | --- | --- |
| 0 | 未标注 | 10,491 |
| 1 | 建筑 | 2,689 |
| 2 | 道路 | 2,227 |
| 3 | 边界 | 793 |

`classes` 保存分类值，加载时据此生成 `grid`。道路在 `grid` 中为 0，其余为 1。按上下左右邻接，初始道路分为 2,223 格和 4 格两个连通区域。校园 PDF 提供平面信息，天桥及其通行关系仍需实地核实。

## 地点与入口

`reference/building-markers.json` 收录 70 个建筑和 19 个场地。建筑名称来自 PDF 文字，坐标按建筑轮廓和场地位置核对。职工公寓使用建筑群代表点，停车棚因分类不清暂未标注。保存地点只修改位置、名称、类型和说明，通行网格由分类决定。

`reference/place-entrances.json` 为各地点提供一个图面候选入口。建筑优先选相邻的主要道路格，其他地点使用附近的主要道路格。候选入口标记为 `map_inferred`，入口位置和通行状态仍需核实。手工设置的入口须位于道路格。封路可使现有入口受阻，入口记录仍可在维护中查看。

`places` 保存地点标记，`place_kinds` 区分建筑和场地，`place_status` 保存说明。状态中的 `entrances` 以地点名称为键，值为含一条入口的列表。入口包含名称、`point`、`enabled` 和可选的 `source`。

## A* 与历史回放

`plan_named_route` 确定起终点的接入格，再调用一次 `astar(grid, start, goal)`。缺少入口时按曼哈顿距离找最近道路格，并标记为待核实的临时接入点。已有入口停用或受阻时提示核对入口。

A* 以 `f = g + h` 决定扩展顺序。`g` 是起点到当前格的步数，`h` 是当前格到终点的曼哈顿距离。每步只移动到上下左右相邻的一格，代价为 1。程序显示路径步数、扩展节点数及扩展顺序，也提示终点不可达。步数用于比较网格路线。

历史记录保存查询当时的分类、地点、入口及 `route_query` 接入信息，并保存路径与扩展顺序。历史回放使用该次查询的快照。搜索播放按已有扩展顺序更新画面，支持暂停和拖动进度。

## 保存与工作台

`open_pdf_project()` 返回地图资料、服务、保存修订号和地图状态。SQLite 存储于 `data/campuspath-integrated.db`，表结构见 [地图数据库](../database/README.md)。地点标记和可选入口保存在同一张地点表。建库或恢复初始地图时读取初始分类、地点和入口资料。每次保存递增内部修订号，导航据此刷新结果。

界面由 `visualization/workspace.py` 和 `visualization/workspace.css` 管理。左侧操作台在导航、地点、历史和维护间切换，宽度可在 25%～33% 调整，地图位于右侧。默认显示底图和地点名称，“图层与布局”可调整地图尺度、图层和聚焦。地点输入框支持名称筛选，地图点选可回填坐标。

维护模式支持点选和框选。 `set_grid_region` 按闭区间修改分类和通行网格。分类、地点和入口共用草稿，最近 20 步可用 Ctrl+Z 撤销、Ctrl+Y 重做。保存时在同一事务内写入整张地图。多会话保存以最后成功写入的内容为准。

导入项目地图 JSON 时校验来源指纹、180×90 分类、地点与单入口，并按分类重建通行网格。导出可使用当前地图或草稿。导入与恢复各替换一次草稿，保存前可以撤销。

地图用半透明分类格表示建筑、道路和边界，路线与扩展节点以格子高亮。绿色实心方框为手工入口，绿色空心方框为图面候选，橙色菱形为受阻入口，灰色空心方框为停用入口。道路核查可选择连通区域并定位，不写入地图数据。
