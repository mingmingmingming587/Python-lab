# 校园地图与道路采集

整理日期：2026-11-03。原阶段：07 采集与核实、11 重绘示意图、12 建筑与道路示意、13 道路网格试算、14 高清图细节。

## 当前地图怎么绘制

“地图资料预览”根据用户提供的校园图重新绘制，支持缩放、拖动、按地点聚焦及显示或隐藏地点名称。建筑、场地和小路仍是图面示意，并非实测地图。

1. `reference/extract_layout.py` 使用 PyMuPDF 提取 `reference/campus-map.pdf` 的地名及图面位置，用 Pillow 从 `reference/campus-map.webp` 提取近似建筑和场地色块。
2. 部分多行名称经过合并，如思源餐厅、工程训练中心、文德楼和大学生活动中心（第三食堂）；停车棚按参考图人工补充近似位置。自动提取仍可能漏字或错分。
3. 本地布局 `reference/campus-layout.json` 供 `visualization/campus_diagram.py` 重绘。画面包括近似建筑占地、场地、小路及经过修正的道路示意线；周边大街不再特别强调。
4. `pages/5_地图资料预览.py` 展示结果。图面坐标不是经纬度，不能直接与 OSM、APK 坐标匹配，也不自动进入 A*。

原图、衍生布局和本地参考资料均被 Git 忽略，公开分发或改编许可仍待确认。准备文件及运行说明见 `reference/README.md`；要重新生成布局，在具备 PyMuPDF 和 Pillow 的 Python 环境下运行 `python reference/extract_layout.py`。

## 道路采集与 A* 试算

“校园道路采集”在图面叠加 **72 行、40 列**网格，行列从 0 开始。格子只是图面区域，不是经纬度或真实米数。记录存入本机 SQLite 中的独立表，不替换模拟地图或历史记录。

1. 准备参考图和布局，打开“校园道路采集”。地图可缩放，行列数字每隔 5 格显示。
2. 可点击“加入已有道路示意线索”，这些粗画的线默认为待核实。也可以新增、修改、删除道路或入口，并记录名称、网格坐标、状态、来源和备注。道路每段须水平或垂直，转弯拆成多段；入口只占一个格子。
3. 按实际核查结果标记“待核实”“已核实可通行”或“已核实不可通行”。入口必须位于已核实可通行的道路网格上，入口本身不会自动打通道路。
4. 选择满足条件的起终点入口，点击“试算 A* 路线”。只有标记为已核实可通行的道路进入搜索；未知区域不通行，冲突时不可通行优先。试算结果显示在当前页面，不写入模拟地图历史记录。

目前六条道路示意线只是待核实线索，不能证明位置、校内外归属、连接或开放情况。**底图更新不会覆盖已保存的道路采集记录**，之前的粗画线索可能与新底图不一致，需要逐条核对。

## 建议的采集步骤

目标是覆盖能找到并核实资料的全部校园区域，不默认不同校区已经连通。可先选 2—3 个地点和连接道路验证方法，再逐区扩展；这不意味着只做一个小区域。

1. 确认资料来源、使用许可、区域范围和采集日期；记录校门、围栏、道路、跨街设施、建筑实际入口和开放限制。
2. 将核实后的入口与道路映射到行列坐标；未核实区域不要默认为可通行。路径点可记录路口和入口，但不会自动转换成网格。
3. 依据 `note/SQLite与地图数据.md` 准备或备份网格数据；图片、坐标或路径点不能直接导入为已核实路网。
4. 选择两个已核实地点，以 A* 计算后逐段和现场比较，记录穿墙、封门、入口偏移、误连接及比例问题，修正后再验证。

## 准确性边界

建筑和场地由参考图颜色近似提取，可能存在噪点、缺口和遗漏；小路线条及地点位置也只是图面近似。网格相邻会被算法视为连通，但现实可能有围栏、高差、跨街或通行限制，较粗的网格还可能漏掉狭路或误连接。

当前 A* 是四方向、单位步长和曼哈顿距离；结果为所录入网格中的最短步数，不等于米数，也不能保证现实中安全或最短。参考资料对照见 `note/校园地图资料.md`。
